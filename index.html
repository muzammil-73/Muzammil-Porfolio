What I've Built

A selection of ML systems, AI-powered tools, and data science projects.

🔍

LLM Git Diff Explainer

A production-ready developer tool that parses Git diffs and uses Gemini to generate structured summaries, risk tiers, and reviewer checklists. Dual interface: FastAPI web server and a piped CLI. Containerized with Docker and CI via GitHub Actions.

Python FastAPI Gemini API Docker GitHub Actions
🧠

RAG Notes Q&A API

A retrieval-augmented generation API that answers questions grounded in your own documents. Ingests PDFs into a Chroma vector store, retrieves semantically relevant chunks, and uses Gemini to generate cited answers. Includes an evaluation harness for measuring retrieval quality.

Python FastAPI LangChain Chroma Gemini API
📊

Telco Customer Churn Prediction

End-to-end ML pipeline predicting telecom customer churn from 7,043 records with 21 features. Trained and compared Logistic Regression, Random Forest, and XGBoost; optimized for recall and ROC AUC on an imbalanced dataset. Includes error analysis and feature importance deep-dive.

Python scikit-learn XGBoost pandas Matplotlib
🌦

Australian Weather Prediction

A data science project analyzing historical meteorological data to predict next-day rainfall across Australia. Full EDA, preprocessing pipeline, and binary classification model evaluation using Accuracy, Precision, Recall, and F1.

Python pandas scikit-learn Seaborn
🌱

Automatic Plant Watering System

An OOP Java program controlling an Arduino irrigation system with moisture sensors, a water pump, and MOSFET. Features a real-time voltage monitoring dashboard via serial communication and a failsafe potentiometer override.

Java Arduino Embedded Systems Serial Comms
